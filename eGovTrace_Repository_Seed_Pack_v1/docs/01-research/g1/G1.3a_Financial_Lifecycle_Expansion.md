# G1.3a — Financial Lifecycle Expansion: NEP → GAA → Allotment → Obligation → Disbursement

**Program:** eGovTrace / Philippine State Control & Assurance Research  
**Research Track:** FMR Reconciliation Experiment  
**Gate:** G1.3a  
**Status:** FROZEN  
**Disposition:** PARTIAL PASS

## 1. Purpose

Determine how far the New Casay FMR financial representation can be followed through the public fiscal lifecycle:

```text
NEP → GAA → Allotment → Obligation → Disbursement
```

The test specifically separates appropriation, allotment, obligation, and disbursement rather than treating them as interchangeable.

## 2. NEP

The FY2025 DBM NEP contains:

- PAP / project code `310203212106000`
- Concreting of Brgy. New Casay FMR
- Brgy. New Casay, BE Dujali, Davao del Norte
- ₱15,000,000

**Disposition: PASS**

## 3. GAA

The FY2025 GAA retains the same project description and ₱15 million appropriation.

**Disposition: PASS**

## 4. Allotment / budget-adjustment representation

NBC 595 Annex A-1 contains:

`310203212279000`  
Concreting of Brgy. New Casay FMR  
₱15 million shown in the adjustment representation as a negative parenthesized amount.

This establishes an official budget adjustment / release representation, but it does **not** by itself prove that ₱15 million was positively allotted at that stage.

**Disposition: PASS for existence of the representation; positive allotment status UNRESOLVED.**

## 5. Identifier continuity

A key discovery is that the identifier in the NEP differs from the identifier shown in the later budget-adjustment representation.

Therefore:

```text
UACS/PAP-looking code ≠ automatically persistent project identity
```

This is classified as a failed persistence assumption, not a government-system defect.

## 6. Obligation

DBM and DA publish financial reporting structures that include current-year obligations. However, the available public evidence did not produce a confidently project-specific New Casay obligation record that could be joined to the project without additional transaction identifiers.

**Disposition: UNRESOLVED**

## 7. Disbursement

DA publishes disbursement reporting and DBM publishes NCA utilization information. However, no project-specific New Casay disbursement record was established.

An agency-level NCA or FAR total must not be attributed to a single FMR without an evidentiary bridge.

**Disposition: NOT ESTABLISHED**

## 8. Lifecycle scorecard

| Stage | Result |
|---|---|
| NEP / programmed | PASS |
| GAA / appropriated | PASS |
| Allotment / adjustment representation | PASS |
| Positive allotment | UNRESOLVED |
| Obligation | UNRESOLVED |
| Disbursement | UNRESOLVED |
| Direct project → payment join | NOT ESTABLISHED |
| Persistent identifier assumption | REJECTED |
| Financial lifecycle reporting exists | CONFIRMED |

## 9. Core finding

The problem is not that financial reporting is absent.

The problem is that public project-level reconciliation weakens after the appropriation/allotment representation unless transaction-level keys can be recovered.

## 10. Frozen disposition

**G1.3a: PARTIAL PASS**

The research established NEP and GAA continuity and identified an official allotment/adjustment representation, but did not establish project-specific obligation or disbursement joins.
