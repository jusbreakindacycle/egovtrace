# G1.3 — DBM Financial Discovery & Join Test

**Program:** eGovTrace / Philippine State Control & Assurance Research  
**Research Track:** FMR Reconciliation Experiment  
**Gate:** G1.3  
**Status:** FROZEN  
**Disposition:** PASS for financial discovery; project-level lifecycle join PARTIAL

## 1. Purpose

Test whether the FMR Watch anchor appears in the public DBM financial ecosystem and whether project-level budget representations can be linked to the FMR candidate without prematurely assuming that budget identity equals project identity.

## 2. Official financial evidence

The investigation identified the following official DBM representations for the New Casay FMR candidate.

### 2.1 FY2025 NEP

**PAP / project identifier:** `310203212106000`  
**Description:** Concreting of Brgy. New Casay FMR, Brgy. New Casay, BE Dujali, Davao del Norte  
**Amount:** **₱15,000,000**

### 2.2 FY2025 GAA

The same project description and ₱15 million appropriation appear in the FY2025 GAA FMR materials.

### 2.3 FY2025 budget adjustment / release representation

A DBM NBC 595 Annex A-1 document contains another New Casay FMR representation with:

**Identifier:** `310203212279000`

The document shows a **(₱15,000,000)** adjustment entry.

The negative-parentheses presentation must not be interpreted as proof of a positive allotment.

## 3. Core findings

### 3.1 DBM public financial source — PASS

Official DBM systems and publications expose searchable/public budget representations.

### 3.2 Exact project-level budget representation — CONFIRMED

New Casay FMR appears explicitly at project level in the FY2025 NEP and GAA.

### 3.3 Financial amount — CONFIRMED at budget representation level

The FY2025 budget representation is ₱15 million.

### 3.4 Direct FMR Watch → DBM ID — NOT ESTABLISHED

No direct public cross-reference from the FMR Watch UUID-like locator to a DBM identifier was established.

### 3.5 Identifier persistence — REJECTED as an assumption

The apparent identifier differs between the NEP representation and the NBC 595 adjustment representation.

Therefore:

> a budget/PAP identifier must not automatically be modeled as the permanent identity of the real-world intervention.

## 4. Amount discrepancy

The DBM budget representation is **₱15 million**, while the DA project reporting states a **₱14.92 million contract cost**.

Difference: **₱80,000**.

This is **not classified as a contradiction or anomaly**.

Possible lifecycle explanations exist, but none was established at this gate.
