# T001 — Repository Initialization

## Objective
Initialize the actual eGovTrace engineering repository as an AI-native, modular monolith workspace.

## Allowed scope
Repository root, docs, prompts, packages, apps, tests, scripts and CI scaffolding.

## Forbidden scope
Production government integrations, real restricted data, autonomous legal/accountability decisions, production credentials.

## Acceptance criteria
- Repository structure exists.
- TypeScript project references compile.
- Test command runs.
- Lint command runs.
- Architecture and ADR artifacts exist.
- Synthetic-data policy is documented.
- No fake production integration is claimed.

## Validation
Run typecheck, test, lint and build.
