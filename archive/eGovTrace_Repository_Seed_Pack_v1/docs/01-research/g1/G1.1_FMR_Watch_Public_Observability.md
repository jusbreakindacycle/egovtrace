# G1.1 — FMR Watch Public Observability

**Program:** eGovTrace / Philippine State Control & Assurance Research  
**Research Track:** FMR Reconciliation Experiment  
**Gate:** G1.1  
**Status:** FROZEN  
**Disposition:** PASS with unresolved field-level access questions

## 1. Purpose

Test whether the selected Farm-to-Market Road (FMR) project record can be publicly discovered and observed through FMR Watch, and whether the portal provides enough project-level information to support later reconciliation against procurement, budget, financial, and physical evidence.

## 2. Anchor project

The anchor was the FMR Watch project associated with the DA reporting on Barangay New Casayuran / New Casay area, Braulio E. Dujali, Davao del Norte.

Observed contextual attributes include:

- 800-meter concrete road
- approximately 5-meter width
- approximately 0.23-meter thickness
- FY2025 DA FMR program context
- reported contract cost of **₱14.92 million**
- construction beginning in March 2025
- completion reported around July 2025
- contractor reported as **Ruplino Seismundo Construction Corp.**
- DPWH Davao del Norte 2nd District Engineering Office identified in the DA reporting as providing supervision / technical oversight
- exact FMR Watch project URL containing a UUID-like locator

## 3. Findings

### 3.1 Public project observability — CONFIRMED

The project is publicly discoverable through the FMR Watch portal and is linked from official DA reporting.

### 3.2 Project-level description — CONFIRMED

The public project representation exposes enough contextual information to identify the intervention candidate by place, dimensions, program context, cost, contractor, and project timing.

### 3.3 Native identifier — PARTIAL

A UUID-like project locator is publicly visible. Its status as a stable native database primary key, public API identifier, or persistent cross-system identifier was not independently established.

### 3.4 Machine retrieval — UNRESOLVED

The live portal/API/schema could not be reliably retrieved during the research window. Exact public field names, API behavior, export capability, version history, and rate/automation constraints therefore remain unresolved.

### 3.5 Cross-system identifiers — NOT ESTABLISHED

No confidently established public FMR Watch cross-reference was found for a PhilGEPS ID, DBM/UACS reference, contract number, DPWH project ID, or payment identifier.

## 4. Evidence interpretation

The FMR Watch record is treated as an **institutional project representation**, not as the real-world intervention itself.

A public project record does not by itself prove:

- that every reported field is independently verified;
- that the associated procurement record is the same transaction;
- that the reported contract amount equals the appropriation or obligation;
- that payment occurred;
- or that physical completion is independently established.

## 5. Reconciliation implications

G1.1 establishes that the FMR domain is experimentally viable because a public project representation exists and can be used as an anchor.

It does not establish that the project's full lifecycle is publicly joinable.

## 6. Frozen disposition

**G1.1: PASS**

The FMR Watch anchor is sufficiently observable to proceed to procurement and financial reconciliation tests.

The unresolved API, field-level, versioning, and cross-reference questions remain explicit research items and must not be silently inferred.
