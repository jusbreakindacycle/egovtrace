# eGovTrace Case A — P00046632VS-CW1 Historical Lineage Adjudication

## Status

**Research branch:** Case A — DPWH Project/Program Identity Recovery

**Question:** Does DPWH Project Component ID `P00046632VS-CW1` provide a defensible institutional identity bridge to the selected 2021 Cabarasan–Dao FMR (`2021-R8-NOS-INFRA-FMRDP-FMR-00547`)?

**Research date:** 2026-09-05

## Executive finding

The available DPWH evidence establishes that `P00046632VS-CW1` is associated with the Cabarasan–Dao FMR description and UACS/PAP `165004050305802` in a DPWH Annual Infrastructure Program document dated **2017-03-29**, while the same UACS/PAP and project description also appear in FY2016 DBM/DPWH budget material.

This produces a strong historical lineage to an **older 2016-era Cabarasan–Dao intervention**, not a demonstrated identity bridge to the selected **2021** intervention.

Therefore:

```text
P00046632VS-CW1 → 2016-era Cabarasan–Dao intervention = SUPPORTED

P00046632VS-CW1 → selected 2021 Cabarasan–Dao FMR = NOT ESTABLISHED
```

The identifier must therefore **not** be promoted as the 2021 project identity.

## Evidence chain

### 1. FY2016 budget identity

DBM's FY2016 General Appropriations Act for DPWH identifies UACS/PAP `165004050305802` as:

> Concreting of Brgy. Cabarasan - Brgy. Dao Farm - to - Market Road, Gamay, Northern Samar

with an allocation of **₱10,000,000** under Northern Samar 2nd District Engineering Office.

Source: DBM FY2016 GAA, DPWH agency-specific volume.

### 2. DPWH Project Component ID

A DPWH Annual Infrastructure Program record dated **2017-03-29** identifies:

- Project Component ID: `P00046632VS-CW1`
- Description: Concreting of Brgy. Cabarasan - Brgy. Dao Farm-to-Market Road, Gamay, Northern Samar — Construction of Concrete Road
- Target: 1.300 lane-km
- Allocation: ₱10,000,000
- UACS/PAP: `165004050305802`
- Implementing Office: Northern Samar 2nd District Engineering Office

This is direct evidence that `P00046632VS-CW1` was used for the same-titled Cabarasan–Dao intervention associated with the 2016-era UACS/PAP.

### 3. Older physical/project performance evidence

CIAP/PDCB CPES reporting identifies an earlier Cabarasan–Dao FMR intervention:

- Contractor: C D U Construction
- Start: 2016-08-28
- Implementing office: Northern Samar 2nd DEO
- Contract/evaluated amount: approximately ₱9.173M
- Performance result: 82.9% satisfactory

This independently supports the existence of a 2016 intervention on the same corridor.

### 4. Selected 2021 project identity

The selected eGovTrace Case A record is:

- FMR code: `2021-R8-NOS-INFRA-FMRDP-FMR-00547`
- Project: Concreting of Brgy. Cabarasan to Brgy. Dao FMR, Gamay, Northern Samar
- Amount: ₱12,500,000
- FY2021 DBM direct-release UACS: `310203206922000`
- FY2021 DBM NEP UACS: `310203206867000`

The 2021 agency-origin report states that the project was under contract with A-Cube Construction and Supply and construction began 2021-08-23.

## Adjudication

### Join tested

```text
2021 FMR code / project
        ↓
P00046632VS-CW1
```

### Result

**NOT ESTABLISHED.**

### Reason

The strongest direct evidence found for `P00046632VS-CW1` places it alongside UACS/PAP `165004050305802` and a ₱10M Cabarasan–Dao intervention that is independently documented in FY2016 budget records. The selected 2021 project is represented in FY2021 budget records under different UACS/PAP values and a different amount (₱12.5M).

No source recovered in this branch demonstrates a formal succession relationship such as:

```text
2016 intervention
→ rehabilitation / continuation / phase relationship
→ 2021 intervention
```

No source recovered establishes that `P00046632VS-CW1` remained the same institutional project identifier after the 2016-era intervention and was reused for the 2021 project.

## False-join control

The following tempting joins are rejected:

### Same route/title

```text
Cabarasan–Dao 2016
≠ automatically ≠
Cabarasan–Dao 2021
```

### Same implementing office

Northern Samar 2nd DEO appears on both records, but this is an organizational relationship, not project identity proof.

### Same corridor / physical road

A later intervention can affect an already-improved corridor. Same physical route does not prove same intervention.

### Same contractor

The older 2016 intervention is associated with C D U Construction, while the 2021 agency-origin report identifies A-Cube Construction and Supply. Contractor change reinforces the need for temporal separation but is not itself identity proof.

### Same general project wording

The title similarity is insufficient to establish continuity between fiscal-year interventions.

## Bridge state after adjudication

```text
2021 FMR
   ↓ CONFIRMED
FY2021 budget / UACS
   ↓
DPWH Project Component ID P00046632VS-CW1
```

The appropriate evidence state for the attempted bridge is:

**NOT ESTABLISHED — HISTORICAL IDENTIFIER MATCH WITHOUT PROVEN 2021 CONTINUITY**

## Research implication

`P00046632VS-CW1` should be retained in the evidence graph as a **historical related record**, not as the canonical 2021 project identity.

This is a useful eGovTrace result because it demonstrates that an apparently strong DPWH-native identifier can still point to a different temporal intervention when the underlying institutional record is examined.
